# 🚀 Object Detection using YOLOv8

This project performs **real-time object detection and multi-object tracking** using **YOLOv8** and **OpenCV**. It detects multiple objects in videos, assigns unique tracking IDs, displays confidence scores, counts detected objects, and saves the processed output video.

---

## 🎥 Project Demo

A short demonstration of the real-time object detection and tracking system.

`assets/videos/demo_video.mp4`

## ✨ Features

- ✅ Real-time Object Detection
- ✅ Multi-object Tracking
- ✅ Live Object Counting
- ✅ Unique Object IDs
- ✅ Confidence Score Display
- ✅ Output Video Generation
- ✅ Built using YOLOv8 and OpenCV

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/priyadarshinipradhan157/Object-Detection-YOLOv8.git
```

Navigate to the project folder:

```bash
cd Object-Detection-YOLOv8
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Usage

### Image Detection

```bash
python src/image_detection.py
```

### Video Detection

```bash
python src/video_detection.py
```

### Object Tracking

